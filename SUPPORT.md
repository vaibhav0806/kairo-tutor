# Support

Kairo Tutor is an early open-source project. Community support is best-effort.

## Questions and troubleshooting

Before asking for help:

1. Read the setup and permissions sections in [README.md](./README.md).
2. Search existing [GitHub Issues](https://github.com/vaibhav0806/kairo-tutor/issues).
3. Run the relevant checks and collect the smallest reproducible example.
4. Inspect `~/Library/Logs/Kairo/kairo-latest.log`, removing personal or sensitive
   information before sharing any excerpt.

Open a bug report for reproducible defects and a feature request for product ideas.
Include your macOS version, Mac architecture, Node and Rust versions, the command you
ran, and the exact observed behavior. Do not include credentials, session tokens,
screenshots of sensitive applications, audio, or full transcripts.

The issue tracker is not a guaranteed-response help desk and cannot provide support
for private forks, custom deployments, or third-party provider accounts.

## Security and privacy

Do not use a public issue for a suspected vulnerability or accidental data exposure.
Follow the private reporting process in [SECURITY.md](./SECURITY.md).

Questions about what Kairo captures, sends, stores, and logs are covered in
[PRIVACY.md](./PRIVACY.md).
